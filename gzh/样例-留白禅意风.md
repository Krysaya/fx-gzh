这是前言正文的第一段。留白禅意风靠**超大留白**与 1px 细线建立层次，不依赖色块与装饰，把「呼吸感」还给读者。

前言第二段：正文关键词会用低饱和墨绿下划线标记，例如「深度思考的能力」这样的核心概念，让读者在克制中快速锁定重点。

## 第一章 认识留白

禅意排版的核心是**克制**。墨绿只在真正需要的地方出现，比如章节编号、短细线、左竖条。

### 1.1 留白的层次

- 锚点层：墨绿加粗，全文不超过 5 处
- 标记层：`#B5C8BC` 下划线，每段 1~3 处
- 容器层：细线 + 大留白，按需出现

引用是禅意风的灵魂：

> 留白不是空白，是呼吸。

这是对引用的一种补充说明，左竖条划定边界，无色块，保持呼吸感。可以写得更长一些来演示多行引用时的左竖条样式，让读者感受到补充说明与主文的区别。

> [!NOTE]
> 提示块用墨绿左竖条 + NOTE 小标签，不用醒目的色块警示。

代码与命令用深色代码块，保持紧凑：

```python
def make_skill(name):
    return f"已生成 {name}"
print(make_skill("gzh-design"))
```

行内代码如 `gzh_format.py` 用浅灰底 + 墨绿字。

排版只改变视觉形态，不改变文字本质。好的排版不抢戏，它只是把「谁更重要」这件事说清楚。
